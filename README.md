Apex Data
Apex Data is a custom fundamental market scanner and data pipeline. 
Designed to bridge the gap between retail trading and institutional analysis, this Java-based backend aggregates hard economic data 
such as Federal Funds Rates and Consumer Price Index (CPI) metrics—directly from the Federal Reserve (FRED) and the CFTC.

Originally born from the University of Forex trading initiative, the engine moves beyond standard technical analysis 
by scoring currency pairs based on underlying macroeconomic momentum and smart-money positioning.

Core Tech Stack:

Java 21

Maven

Jackson (JSON Data Binding)

Native HTTPClient
